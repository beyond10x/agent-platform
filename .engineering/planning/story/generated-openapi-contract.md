## Context

A handwritten OpenAPI file can drift from Axum routes, request bounds and Serde DTOs. Integrators need one deterministic document whose routes and schemas are checked against the executable API.

## Acceptance

A dedicated Rust crate projects every public route, request, response and problem document into deterministic OpenAPI 3.1. `/openapi.json` serves exactly those generated bytes with no-store and nosniff headers. Tests fail on route/projection disagreement, schema drift or nondeterministic output, and the gate records a stable digest.

## Context

A handwritten OpenAPI file can drift from Axum routes, request bounds and Serde DTOs. Integrators need one deterministic document whose routes and schemas are checked against the executable API.

## Acceptance

A dedicated Rust crate projects every public route, request, response and problem document into deterministic OpenAPI 3.1. `/openapi.json` serves exactly those generated bytes with no-store and nosniff headers. Tests fail on route/projection disagreement, schema drift or nondeterministic output, and the gate records a stable digest.

## Implementation record — 2026-08-31

Implemented `agent-platform-api` as the shared route/problem contract and `agent-platform-openapi` as its deterministic OpenAPI 3.1 projection. Axum consumes the catalog's path constants; executable tests prove all 14 method/path operations are registered behind the declared authentication boundary and carry request, response, problem, path-parameter and success-status schemas. The service and CLI emit identical bytes at SHA-256 `7aab7b4ee044bc8709c63aaee3a3c64a3a6aee11b97a4dd06bd20b7b37585d3a`; `/openapi.json` is public with `no-store` and `nosniff`.

# Vision: The generic agent platform

## Outcome

An authenticated tenant member can define an agent, compile a narrow connector capability surface, submit governed work manually or through a trigger, and inspect the durable record through a generic API.

## Exit Evidence

The walking slice creates and activates an immutable agent revision, previews a deterministic tool projection, submits an idempotent task, and reads its attributed state. The later production closure executes that task through Harness and Connectors and is adopted by the babelforce ai-agent-platform without introducing babelforce vocabulary here.

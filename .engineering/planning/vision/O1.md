# Vision: Governed reach

## Outcome

Every agent-platform request and tool call is attributable to a verified tenant principal and is limited by the intersection of Identity authority, the active agent revision, its compiled capability profile, and the current Connector Grant.

## Exit Evidence

A cross-tenant request, an ungranted capability, a revoked delegation, and a stale Connector description are each refused by name before an effect occurs; accepted effects carry the task, run, actor, executor, capability, and Connector audit references.

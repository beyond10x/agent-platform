# Vision

An authenticated tenant member defines an agent, projects the overwhelming detail of connected
vendor APIs into the small capability surface that agent actually needs, submits work manually or by
trigger, and can inspect exactly what ran under whose authority.

Agent definitions, mappings and revisions are data. A live agent is never silently rewritten. Every
task pins its revision and authority, every external effect is independently admitted by Connectors,
and every attempt leaves evidence suitable for comparison, rollback and later improvement.

This is a generic foundation. A downstream product may supply its own authoring model, channels,
knowledge, terminology, UI and packaging, but compiles those choices into the same product-neutral
revision, capability, task and evidence contracts.
